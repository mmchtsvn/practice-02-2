Конспекты

Тема 1: Введение в HTML
HTML — это стандартизированный язык разметки, который используется для создания структуры и определения контента веб-страниц с помощью специальных тегов. Он служит фундаментом всемирной паутины, позволяя браузерам правильно отображать текст, изображения, ссылки и другие элементы интерфейса.
Смотреть лекцию →
Тема 2: Семантическая разметка
Семантическая разметка — это использование специальных HTML-тегов, которые явно описывают смысловое назначение каждого блока веб-страницы для браузеров и поисковых систем. Она делает код структурированным, значительно повышая доступность сайта для людей с ограниченными возможностями и улучшая его SEO-показатели в поисковой системе.
Читать подробнее →
Тема 3: Списки
Списки в HTML используются для структурирования контента и бывают трех видов: маркированные(<ul>) для произвольного порядка, нумерованные(<ol>) для последовательных шагов и списки определений(<dl>). Внутри первых двух типов списков каждый отдельный элемент обязательно оборачивается в тег <li>.
Узнать больше →
Тема 4: Гиперссылки
Гиперссылки в HTML создаются с помощью тега <a> и связывают веб-страницы друг с другом или с внешними ресурсами. Главным атрибутом является href, который указывает путь к целевому адресу, превращая обычный текст или изображение в кликабельный элемент.
